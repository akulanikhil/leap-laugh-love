# Branching Strategy

## Trunk-Based Development

We chose trunk-based development for our git workflow because we don't see ourselves doing month-long branches. This approach keeps our codebase more cohesive and allows for faster integration of features. Additionally, trunk-based development aligns better with our team's development pace, which is why we didn't opt for Git Flow.
